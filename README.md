# Dental Surgeons — Correct Responsive Website

This ZIP contains the working website implementation rather than a screenshot/mockup.

## Files
- `index.html` — complete page structure
- `style.css` — responsive design matching the supplied navy/gold/white concept
- `script.js` — mobile navigation, appointment modal, form feedback, testimonial slider, active navigation
- `assets/` — individual image assets used by the site

## Image assets
- `clinic-operatory.jpg`, `dentist-consultation.jpg`, `patient-treatment.jpg`, `clinic-reception.jpg`, `smile-portrait.jpg`, `happy-patients.jpg`, `implant-care.jpg`, `kids-dentistry.jpg` are locally generated dental photography assets.
- `dr-aamir-supplied.jpg` and `dr-aamir-clinic-supplied.jpg` are cropped from the Dr. Aamir images supplied in the conversation; they are used only as the doctor imagery.
- `logo.svg` is a custom Dental Surgeons logo created for this website.

No Instagram screenshot or website mockup is used as a website image asset.

## Run
Open `index.html` directly in Chrome/Edge/Firefox. No build step or server is required.
