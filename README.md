# Dr. Aamir Rafiq — Responsive Dental Website

Static, deployment-ready website built with:
- `index.html`
- `css/style.css`
- `js/script.js`
- `assets/` containing the supplied website images

## Included
- Responsive desktop, tablet and Android/mobile layouts
- Mobile navigation
- Smooth scrolling
- Scroll reveal animations
- Gallery lightbox
- Back-to-top control
- Click-to-call appointment and clinic buttons
- No frameworks or build step required

## Run locally
Open `index.html` in a browser, or serve the folder with any static web server.

All supplied images are kept locally in `assets/` so the site does not depend on external image hosting.
